# F2 第三步 · 术语提取（方案，待评审，未实现）

每门课一次性提取术语表。不做 F3 的审查接线，不做用户界面。

输入：slicer 的 `SliceSet`（含 `units` 的 bbox / `font.size_rank` / `image_adjacency`）
与 parse-service 的 `pages`（含 `images`）。

实测语料：22.081J（39 页，有人工金标准 v1.1 共 44 条）。测量日期：2026-08-21。

## 0. ⚠️ 图注通道不能靠 `image_adjacency`——信号在关键页上不存在

任务书要求「图注判定用 `image_adjacency` 与 `size_rank` 联合」。
**在本语料上这条走不通**，且不是阈值问题。

### 0.1 实测

v1.1 的 **17 条图注术语全部来自 p20 与 p27** 两页。而这两页：

| 页 | 位图数 | 矢量绘制数 | 块数 | 该页贡献的金标准图注术语 |
| --- | --- | --- | --- | --- |
| p20 | **0** | 51 | 9 | 5 条 |
| p27 | **0** | 120 | 31 | 12 条 |

**两页的位图数都是 0**——图是**矢量绘制**的，不是嵌入位图。
`image_adjacency` 由 `get_image_rects()` 驱动，没有位图就没有矩形，
故这两页**每个块的 `image_adjacency` 恒为 null**（实测 `adj=False, rel=None` 全页成立）。

用「邻接 + 字号」联合判定，在贡献了全部 17 条金标准图注术语的两页上，**命中 0 条**。

全篇对照：22.081J 共 22 张位图、468 个矢量绘制；无位图但矢量绘制 > 30 的页恰好就是
p20 与 p27 这两页。

### 0.2 改用 PRD §8.1 自己写的机制

PRD §8.1 对图注通道的原话是「识别**无句法结构的孤立名词短语簇**」——
它说的就不是邻接。实测这个形态信号非常干净：

| | p27（图表页） | p22（正文页） |
| --- | --- | --- |
| 块数 | **31** | 8 |
| 每块词数 中位 / 最大 | **1 / 5** | 7.5 / 28 |
| `size_rank` 取值档数 | **2**（0.49 正文、0.98 标题） | 4 |
| 含句末标点的块 | **1 / 31** | 2 / 8 |

图表页的特征是：**块多、每块极短、字号高度一致、几乎没有句末标点**。
正文页四项全部相反。

**`image_adjacency` 保留为佐证信号**，用于确实有位图的页（22.081J 另有 22 张位图
分布在 p13/p21/p24/p30/p31 等）；但它**不是主判据**，缺失时不影响判定。

### 0.3 这不推翻 2a 的决定

2a 刻意不做 role 分类、把判断留到这一步，理由是「单靠邻接会误收标题」
（`REAL HEAT ENGINES` 的 `size_rank` 0.96 也被判为 `is_adjacent`）。那条依然成立，
只是本次发现邻接的问题比预想的更重：**它不仅会误收，在关键页上还根本不存在。**
`size_rank` 用来排除标题这一点原样保留（§2.2 的 F3 规则）。

## 1. 召回率有结构性上限，不是 100%

17 条图注术语在**文本层**的可达性（自动提取只能看文本层）：

| 类别 | 条数 | 说明 |
| --- | --- | --- |
| 连续字符串可直接命中 | **12** | 如 `Pressurizer` `Steam generator` `Alternator`（p27 的块） |
| 需拼接相邻碎片才可得 | **2** | `control rod`（p27 拆成 `Control` + `rods`）、`cooling tower`（`Cooling` + `tower`） |
| **文本层根本没有** | **3** | `heat exchanger` / `makeup water` / `steam turbine`——全在 p20 |

**p20 的标签是转成矢量轮廓的文字。** 渲染出来 `Furnace` / `Heat exchanger` /
`Steam turbine` / `Makeup water` / `Condenser` 清晰可见，人能读，PyMuPDF 读不到
（该页 9 个块里没有任何一个是图内标签）。

> **图注通道的召回率上限 = 14/17 = 82%。**
> 报告里必须写明这条，否则 82% 会被读成「方法不够好」，
> 而实际是「文本层没有这些字」。突破它需要 OCR 或多模态，本次不做。

正文通道同理：27 条中有 4 条（`breeder reactor` `fission product` `nuclear fission`
`uranium enrichment`）在文本层没有连续字符串——它们是人工从上下文归纳的词形
（课件写的是 `breeders`、`fission products`、`235U produces energy by fission`、
`enrichment`）。**上限 23/27 = 85%**，需要词形归一才能接近。

## 2. 两条通道的启发式

### 2.1 正文通道

| 编号 | 启发式 | 信号 | **误收风险** | 缓解 |
| --- | --- | --- | --- | --- |
| **B1** | 加粗词组 | `span.bold` | 幻灯片常用加粗做**强调**而非定义（`NOT` `must` `all`） | 过停用词表；要求 ≥2 个实词或首字母大写；单词长度 ≥ 4 |
| **B2** | 标题内名词短语 | `size_rank ≥ 本页最高档` | 幻灯片标题多是**整句**（`HOW DOES A POWER PLANT WORK?`） | 只取标题内 ≤3 词的名词短语；含疑问词/动词的标题整条丢弃 |
| **B3** | 跨页高频短语 | n-gram 跨页计数 | **高频 ≠ 术语**（`energy use` `power density` 都高频，前者不是术语） | 要求跨 **≥2 页**；过停用词；要求在至少一次出现时首字母大写或与 B1/B2 同现 |
| **B4** | Glossary 页 | 标题含 `glossary`/`definitions`/`terms` | 低 | 本语料**无此页，实现但不触发** |
| ~~B5~~ | ~~定义框~~ | — | — | **本次不实现**，见下 |

**B5 定义框不做**：PDF 里定义框没有稳定信号（可能是矩形描边、可能是背景色块、
可能只是缩进），而**本语料没有任何一页是这个形态**。凭空写一个检测器
等于造一个没有依据的启发式——这正是本项目反复避免的事。记 TODO，遇到样本再做。

**不引入 NLP 依赖**：无 spaCy / NLTK。名词短语用「大写模式 + n-gram + 自带停用词表
+ 复数归一」近似。这是保守近似，会漏——**符合「宁漏勿错」的误差方向**。

### 2.2 图注通道

**两级判定：先判页，再判块。** 分两级是因为「短块无标点」在正文页上也会命中
（页脚、页码、项目符号碎片），只有在图表页语境下它才是图注信号。

**第一级 · 图表页判定**（满足 ≥3 条）

| 编号 | 条件 | 阈值来源 |
| --- | --- | --- |
| P1 | 块数 ≥ 12 | **占位待定**。实测 p27=31、p20=9；正文页 p22=8。确定路径见 §3.2 |
| P2 | 每块词数中位 ≤ 2 | **实测依据**：p27 中位 1，正文页 p22 中位 7.5，间隔大 |
| P3 | 含句末标点的块占比 ≤ 20% | **实测依据**：p27 为 1/31 = 3%，p22 为 2/8 = 25% |
| P4 | `size_rank` 取值档数 ≤ 3 | **实测依据**：p27 为 2 档，p22 为 4 档 |
| P5 | 有位图且 ≥3 个块 `is_adjacent` | **佐证项**，缺失不否决（p20/p27 上恒为假） |

⚠️ 注意 **p20 只有 9 个块**，P1 判不出来。这是已知的：p20 的图内文字不在文本层，
它本来也提不出术语（§1）。故 P1 的阈值**不为了把 p20 捞进来而放宽**——
放宽只会把正文页误判成图表页，而 p20 即使被判为图表页也提不出东西。

**第二级 · 块级图注判定**（图表页内，全部满足）

| 编号 | 条件 | 理由 / 阈值来源 |
| --- | --- | --- |
| F1 | 词数 ≤ 5 | **实测依据**：p27 块最大 5 词 |
| F2 | 无句末标点 | **实测依据**：图内标签不成句 |
| F3 | **`size_rank` 不是本页最高档** | **这是排除标题的那一条**。`REAL HEAT ENGINES` 的 0.96 与 `NUCLEAR FUEL` 的 0.98 都是本页最高档，直接被排除 |
| F4 | 非纯数字 / 单位 / 温度 | 排除 `(330 ◦C)` `(280 ◦C)`。对应判据 G4（单位不进表） |
| F5 | 非页眉页脚样板 | 复用 retrieval R03 的样板判据 |

**碎片拼接**：同页、同 `size_rank`、bbox 间距 < 1.5 行高且横向或纵向对齐的相邻块，
拼接后再过一次 F1–F5。这条为的是 `Control`+`rods`、`Cooling`+`tower`（§1 的 2 条）。
间距阈值 **占位待定**，沿用 geometry 的 `ADJACENCY_MAX_GAP_LINES`，
不新造一个数。

**最后统一过 G1–G5**（`glossary_criteria.md` 的冻结判据，不重造）：
领域限定性 / 匹配无歧义 / 讲解必要性 / 翻译有障碍 / 非专有名词。
自动化只能近似 G1、G4、G5（停用词表、单位正则、大写专名模式）；
**G2、G3 需要语义判断，自动提取做不到**——故所有条目带 `confidence`，
G2/G3 未经验证的一律不给 `high`。

## 3. 金标准与自证问题

### 3.1 自证到什么程度：可以量化，不必空谈

v1.1 是**人工 + 模型辅助**整理的，与本次方法不独立。但自证的程度**因来源而异**，
可以拆开说：

| 部分 | 人工当时用了什么信息 | 自动提取能用什么 | 是否构成自证 |
| --- | --- | --- | --- |
| p27 的 12 条图注术语 | 文本层 + 渲染图 | 文本层 | **部分自证**——同一批字面 |
| **p20 的 5 条图注术语** | **只能来自渲染图** | 文本层拿不到 | **不构成自证**：人工用了自动方法没有的信息，这 5 条注定是「漏」 |
| 27 条正文术语 | 文本层 + 判据 G1–G5 | 文本层 + G1/G4/G5 的近似 | **部分自证**——判据同源 |

所以召回率这个数**偏高的方向是明确的**：分子里那些「自动能命中的」，很大程度上
正是人工当初也从同一批字面里读出来的。它衡量的是「自动提取能否复现我当时的判断」，
**不是**「自动提取能否找全课件里的术语」。

### 3.2 三条应对，其中第 2 条不受自证影响

**① 阈值不在 22.081J 上反复调。**
优先取**结构性判据而非数值阈值**（F3「不是本页最高档」是比较、不是阈值；
F2「无句末标点」是布尔）。必须定数的（P1/P2/P3/P4/F1）一律标明它是在 22.081J 上
定的，且**只定一次、不迭代**。调参与报告用同一份数据的自证，靠「不迭代」压到最低。

**② 并列报告「新发现条目」——这个数不受自证影响，方向还相反。**

> 自动提取找到、但**不在 v1.1 里**的条目，人工逐条判定是否真术语。

- 若新发现全是误收 → v1.1 作为金标准是可信的，召回率可以照读
- 若新发现里**有真术语** → **v1.1 本身有遗漏，召回率的分母是错的**，
  此时召回率再高也说明不了什么

第二种情况恰恰是自证问题的解药：它检验的是金标准，而不是被金标准检验。

**③ 报告里写明上限**（§1 的 14/17 与 23/27），并把召回率拆成
「相对可达上限的召回」与「相对 v1.1 全表的召回」两个数。
前者衡量方法，后者衡量端到端能力，混在一起会把结构性缺口读成方法缺陷。

### 3.3 不做的事

- **不修改 v1.1**。它已冻结，且 §8.2 实验期间不得修改。新发现只记录，不合并。
- **不扩到第二门课建独立金标准**。成本高于本次收益；且 14.129 有 8 页受限内容、
  11.201 是规划类（`glossary_criteria.md` 的 G5 专有名词边界在该学科未理清，
  已是 A 类脚本的既有 TODO）。

## 4. 输出 schema（草案）

按要求「为将来留好结构」：每条带来源与命中的启发式，
既能日后加人工入口，也能改成「低置信不计入审查分母」。

```jsonc
{
  "course": "22.081J",
  "source_file": "MIT22_081JF10_lec01b.pdf",
  "extractor_version": "0.1.0",
  "ruleset_version": "glossary-extract-1.0",
  "criteria_ref": "实验脚本/A类规则计算脚本/examples/glossary_criteria.md",
  "terms": [
    {
      "en": "steam generator",
      "surface_forms": ["Steam generator"],
      "source": "figure_caption",          // body_text | figure_caption
      "heuristics": ["F-CLUSTER", "F-SHORT"],   // 命中的启发式编号，可多条
      "confidence": "medium",              // high | medium | low
      "confidence_reason": "图表页孤立短块；G2/G3 未经语义验证",
      "pages": [27],
      "occurrences": 1,
      "evidence": [
        { "page": 27, "block_id": "p27-b11", "bbox_norm": [0.31, 0.42, 0.46, 0.45] }
      ],
      "zh": [],                            // 本次不做翻译
      "flags": ["single_occurrence", "joined_from_fragments"]
    }
  ]
}
```

**`confidence` 的分档规则**（不是模型打分，是规则）：

| 档 | 条件 |
| --- | --- |
| `high` | 命中 ≥2 条独立启发式，且跨 ≥2 页出现 |
| `medium` | 命中 1 条启发式，或单页出现但通过全部 G1/G4/G5 近似 |
| `low` | 仅靠频次命中，或拼接得到，或含日常词 |

这三档直接支撑那条「低置信不计入审查分母」的未来路径——
届时只需按 `confidence` 过滤，不必让用户做任何事。
