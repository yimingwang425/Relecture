# 环境重建 · venv 版本快照

2026-09-09 清理仓库时删除了 6 个 `.venv/` 与 2 个 `node_modules/`（约 1.5G）。
**各包的安装命令与本地兄弟包顺序在各自 `README.md`，本文件不复制。**

本文件只补 README 缺的那一件事：**删除当时的确切版本**。

## 为什么需要这份快照

`pyproject.toml` 里依赖是浮动的（`pymupdf>=1.24`、`numpy>=1.26` …），**没有 lockfile**。
直接重建会装到更新的版本。风险不是抽象的：
`parse-service/tests/golden/*.json` 是 pymupdf 抽出来的 golden file，
pymupdf 一变，文本抽取与几何可能变 —— **golden 测试就是这件事的探针**。

重建后若 `parse-service` golden 测试红，先比对下表版本，再判断是真回归还是版本漂。

## Node

`web/`、`supabase/` 都有 `package-lock.json`，用 `npm ci` 精确还原，无此问题。

## 不要顺手删 `retrieval/cache/`

清理磁盘时它看起来像可再生的中间产物（54M，不入库）。**它不是。**
理由写在 `retrieval/retrieval/embed.py` 的模块 docstring，
一句话版：OpenAI 换掉 `text-embedding-3-small` 背后的模型不会有通知，
缓存键不变而向量变了，**重跑数字不同，且你会以为是代码 bug**。
本文件不复制那段论证，读源文件那一份。
