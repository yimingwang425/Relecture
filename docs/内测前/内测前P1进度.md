## 二、两件事各自做了什么

**① `deck_uploaded.restricted_pages_excluded` 停止说谎（F68 / F69）**

改写 `null`（= 未检查），移出必需清单，`schema_version` → `f1-events-5`，存量 `0` 不回填。

**② GapChecker 接进生产，不加开关（F70 / F71）**
Haiku 构造搬进 `explain/gap.py::build_model_gap_checker`（实验侧与生产侧共用一份）；
`GuardedGapChecker` 接住异常**与 5 s 超时**，讲解照常返回；`explain_turn` 新增 `gap_*` 列（不进必需清单，F76）；
G03a 限定语的跳过页来自 `documents.unusable_pages`。
