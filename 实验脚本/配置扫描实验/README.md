## 一、为什么要有这个实验

`F2开发.md` §11.1 记的三条里有两条指向它：

| 项 | 说明 |
| --- | --- |
| 审查 agent 在 v1 指标集上**无实验支撑** | 第 0 周唯一测出差异的维度 v1 不用；v1 要用的三维在那次实验中两组重合 |
| §9.1 **成本画像失效** | 62% 的触发率几乎全部由 `term_annotation` 驱动，该维度下线后应趋近无审查基线 $0.0154 |

**这两件事是同一个数（重生成触发率）的两个方向的读法**，所以必须**同源**——
同一次运行、同一份日志：

| | 触发率高 | 触发率低 |
| --- | --- | --- |
| 审查 agent 有没有用 | 有用，核心差异化成立 | **在做无用功** |
| 单会话成本 | 成本画像不改善 | 成本阻塞项自己消失 |

**§9.1 现有的 62% / $0.590 / 2.55× 全部测自含 `term_annotation` 的配置，
不代表 v1，不得用于任何推算。**

## 三、为什么这次可以含检索，而第 0 周不行

第 0 周排除检索的理由是「两组可能取到不同片段，连输入都不一样，对照就废了」。

本轮的检索 query = **本轮提问原文**，不含历史改写（口径 X01，
依据 PRD §7.5「检索意图单一，不需要多跳推理」）。由此得到一条结构性质：

> **检索结果只取决于提问，与配置点、与条件、与对话历史全部无关。**
> 每轮只检索一次，两组共用同一份 `ContextPack`，签名进日志。

这从**结构上**消掉了当年那个风险，而不是靠约定。`verify_scan` 查两条：
同一 (臂, 点, 轮) 下各组的 `retrieval.signature` 与 `question` 都必须逐字相同。

> **键必须含臂。** 两条臂用不同的提问序列却都跑 P0，只按 (点, 轮) 分组会报出
> 一个并不存在的分歧——**假跑第一次运行就撞上了这个**，说明守卫本身也需要被验证。

## 四、噪声压得住到什么程度（诚实版）

| 想回答的问题 | 能不能答 | 依据 |
| --- | --- | --- |
| 触发率是不是**近零**（全局） | **能** | 阶段 2 后全部点合计 60 个有审查轮次；事件 ≤2 则 95% 上界 ≈ 6%，足以推翻 §9.1 的 62% 画像 |
| 某个点的触发率**是高还是低** | 勉强能，**靠跨轨同向重复** | 单点 n=12，观测 1 次与 6 次事件的 95% CI 分别约 [0.2%, 34%] 与 [21%, 79%]——**两者重叠**。证据来自 R17 的纪律，不是单点数字 |
| 触发率**是多少**（数值） | **不能** | n=12 时 ±25pp。压到 ±10pp 需每点 n≈100，5 点约 1000 次生成 ≈ $18 |
| 拐点**在哪一档** | 能定位到档，不能定位到阈值 | 只能说「P2 与 P3 之间开始出现」，不能说「区间宽度小于 X 时开始」 |
| 成本是多少 | **能，且比触发率可信得多** | token 是确定量，方差只来自输出长度；成本臂是 15 轮实测 |

## 六、守卫（每条都有反向验证，见 `tests/test_guards.py`）

| 守卫 | 反向验证 |
| --- | --- |
| 点内指纹唯一 | 轨迹中途换配置 → 红 |
| 各点指纹互不相同 | 两个点写成同一份配置 → 红 |
| 点间 `metric_set_id` 一致 | 混入另一个指标集 → 红 |
| 拒绝历史口径 | 混入 `CONFIG_VERSION 1.1` 的四维批次 → 红 |
| 计分维度恰为 v1 三维 | `term_annotation` 溜回 `counted_dimensions` → 红 |
| 检索同一性 | 两组签名不同 → 红 |
| 提问同一性 | 同一格里提问不同 → 红 |
| 配置点可分性（sanity） | 5 点必须产出 5 个不同请求指纹 |
| 判读带边界 | 边界值必须归入**有结论**的那一带 |
| E10 两种形态可区分 | 「分段规避」与「确实简洁」必须给出不同结论 |
| E10 的分解是恒等式 | `字/段之比 == 总字数之比 ÷ 段数之比` 必须逐点成立——**这是它不需要阈值的全部理由** |
| 分解不谎报「讲短」 | 总字数**上升**时不得报「真的讲短 N%」（阶段 1 的 P1 就是这个形态） |

`drift.verify` 的「批次指纹一致」那条**被显式滤掉**并注明原因：
传 `None` 会让它打印一个恒为 ✓ 的行，那是空转的检查（通则七 #5）。
