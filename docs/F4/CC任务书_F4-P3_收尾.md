### 3. 新增口径 F67

**写 CHECK 约束时，必须对「键缺失」单独求值一次，确认它返回 false 而不是 NULL。**

理由：**结果为 NULL 的 CHECK 是通过的**。这不是 `f4_event_slice_ids_ok` 一条的性质，是所有 CHECK 的性质——它的失败形态与「护栏空转」完全一致：约束在表上、看起来在防、实际放行。R18 补了这一条的边界，但下一条 CHECK 不会自动继承。

来源：P1 写交付 SQL 时发现（`NULL = '0'` 求值为 NULL，故改用 `is not distinct from`）。
