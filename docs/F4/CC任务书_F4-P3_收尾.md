## 做什么

### 1. PRD 四处修改

沿用 PRD 既有的修改体例：**不删原文**，加带日期的修订块，写明依据。

| 位置 | 改什么 | 依据 |
| --- | --- | --- |
| **§7.1** | 「术语表三处复用」→ 改为**当前零处复用**。审查侧分母已下线（§8.1）、检索信号从未接入（选型走 T0，术语表不在路径上）、F4 决定不用。**不删 `glossary/` 代码**，但 §8.1 的重启条件加第三条：**届时确有消费方** | F4 方案 §一 |
| **§3.1** | 护栏指标「重复提问率」：单位从**概念改为切片**；分子从**用户标记改为同一会话内同一 `slice_id` 被重复命中**。两个误差方向各写一句：切片粒度使同页多概念被计成重复（**高估**，护栏偏保守）；`session_id` 当前按页面加载切分使会话内重复被**低估**。**写明两者方向相反，不得相互抵消着读** | F4 方案 §二 |
| **§5.1 F4** | 「记录用户标记为没看懂的**概念**」→ **切片**；并注明第一件事（风格配置跨课程跨会话继承）在 F1 已完成，F4 只补了一条会红的断言 | F4 方案 §一、§四 |
| **§13.0** | 新增事件 `confusion_mark_created`（字段照 P2 实际落地的写，不照方案写）；讲解轮事件的 `slice_ids` 列为必需字段 | P1 / P2 |

**§3.1 那一处最容易改浅。** 原文写的是「概念识别可复用 F4 的通道」，
要改的不只是名词——**分子从依赖用户点击改成不依赖**。理由必须写进去：
真正没懂的人的典型行为是反复追问而不是点按钮，分子挂在点击上等于要求用户
先承认没懂才能测出他没懂。这是护栏在最需要它时不触发的形态。
