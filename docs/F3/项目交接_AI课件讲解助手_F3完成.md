## 一、F3a · 配置扫描对照实验

### 1.1 为什么不做「默认 vs 极端」二元

F2 交接文档指出的最大缺口：**审查 agent 在 v1 指标集上无实验支撑**——
第 0 周唯一测出组间差异的是 `term_annotation`，而 v1 不用它；
v1 要用的三维在那个实验里两组曲线基本重合。

原计划的救援是「用极端配置重测」。**这只是把外推方向反过来**：
从「中庸配置的结论外推到全体」变成「极端配置的结论外推到全体」，
而真实用户会选什么配置，F1 还没做。这是通则七第 6 例的形态（观测范围与应用范围错配）。

改为**配置扫描**：把配置偏离程度当自变量，取 5 个点，每点跑有审查 / 无审查。
产出从「审查有没有用」变成「**审查的收益在配置空间哪个区域出现、拐点在哪**」——
外推问题变成查表问题，F1 拿到真实配置分布后落在曲线上即可。

**用配置点换轮次**：第 0 周已证明三维在 15 轮内不随轮次衰减，
再跑 15 轮拿不到新信息，配置点是新信息。

### 1.2 §7.1 与 §7.2 是同一个数的两面

要测的核心量是 **v1 三维配置下的重生成触发率**，它同时是两件事的答案，
**而两个答案方向相反**：

| | 触发率高 | 触发率低 |
| --- | --- | --- |
| 审查有没有用 | 有用 | **在做无用功** |
| 单会话成本 | 画像不改善 | 成本阻塞项自己消失 |

含义：**一次实验同时回答两问**，触发率、达标率、逐轮 token 与成本必须同源、同一份日志。

### 1.3 五个配置点

| 点 | `paragraph_length` | `chinese_ratio.min` | 偏离度 |
| --- | --- | --- | --- |
| P0 | 30–120 | 0.85 | 0（默认，与第 0 周同配置） |
| P1 | 40–90 | 0.85 | 轻 |
| P2 | 25–55 | 0.85 | 中 |
| P3 | 15–40 | 0.85 | 强 |
| P4 | 30–120 | **0.95** | 语言轴单点 |

只扫偏短方向（让 LLM 多写从来不难）；引用长度不作自变量
（它是 §12.1 的合规常量，真实用户不会调），改由提问诱发。

**配置同时驱动 prompt 与判定**——只收紧判定不改 prompt，触发率上升是平凡结论。

### 1.4 主判据：跨点单调性，不是逐点分类

原设计是逐点判读带（≤1/12 近零 / ≥6/12 高 / 中间不可分辨）。
问题是最可能的结局为 **P2/P3 落进中间带，恰好在最关心的两点上宣布没结论**。

改为：**触发率沿 P0→P3 单调不减，且 ≥2 条轨迹同向**。判读带降为辅助，只用来定位拐点。
依据是 R17（差异须在多个独立条件下同向重复），这里独立条件有两组：**轨迹 × 轴上位置**。

### 1.5 结论

```
轨 1: [0.000, 0.333, 0.333, 0.500]
轨 2: [0.000, 0.333, 0.333, 0.500]
```

**两条独立轨迹逐点完全重合，主判据成立。**

| | 有审查达标率 | 无审查达标率 |
| --- | --- | --- |
| **P0（默认）** | 1.000 | **1.000** ← 第 0 周的结论在这里复现 |
| P1 | 1.000 | 0.667 |
| P2 | 1.000 | 0.667 |
| **P3（最严）** | 1.000 | **0.417** ← 两组分开 |
| P4（语言 0.95） | 0.917 | 0.750 |

> **第 0 周「两组曲线基本重合」的结论被局部推翻了。
> 审查 agent 的价值随配置偏离默认的程度出现，不是全有全无。
> 第 0 周测不出来，是因为它只测了一个点——而那个点恰好是两组重合的点。**

配套三个数：**拐点在 P0 与 P1 之间** · **P3 上 0.417 → 1.000** · **触顶失败 1/180**（第 0 周 13/45）。

触发归因：`paragraph_length` 29 次、`chinese_ratio` 4 次。

### 1.6 成本

| | P0（默认） | P3（最严） |
| --- | --- | --- |
| 有审查 · 单会话 | **$0.2971** | **$0.3245** |
| 无审查 · 单会话 | $0.2616 | $0.2201 |
| 触发 / 15 轮 | 0 / 15 | 8 / 15 |
| 平均输出字数 | 783 | 502 |

**对 F1 的答案：P3 这一档可以开放。** 最严配置只贵 1.09×——
即使触发率 53%，成本几乎没涨，因为 P3 的输出本来就短，重生成重写的是短文本。

**P0 的 1.14× 不可区分于零**（0 次触发、n=1 轨）；**P3 内部的 1.47× 可以报**（9 次重生成撑着）。

与第 0 周并列（**不覆盖**）：$0.2971 vs $0.590，触发率 0/15 vs 62%。
下降**几乎全部来自维度**（四维→三维），不是检索。

分布（不只报均值）：单轮成本 P50 $0.0141 / P90 $0.0225；单轮延迟 P50 13.7 s / **P90 22.4 s**。

### 1.7 分段规避：达标可以靠多敲回车

`paragraph_length` 量的是**平均**段落字数。P3 是 15–40 字/段，模型有两条路：
真的讲简洁，或者**多敲回车**（同样字数切成更多段）。**第二条稳过判定。**

按被测量自身的定义式分解（`字/段 = 总字数 ÷ 段数`，取对数后可加，**无阈值无自由参数**）：

```
P1: 字/段 0.927× → 真的讲短 83% / 分段 17%
P2: 字/段 0.606× → 真的讲短 36% / 分段 64%
P3: 字/段 0.420× → 真的讲短 28% / 分段 72%
```

**机制随偏离程度切换**：轻度收紧时模型真的压缩，收得越紧越转向分段。
成本臂（真实提问序列）上是 51% / 49%——**构造过的扫描臂把分段比例推高了，两个数分开报**。

**产品含义**：选了「很简洁」的用户在最严档拿到的主要是分段，而**审查看不见这个失败**。
根因是 PRD §8.1 的「详细程度 = 平均段落字数、**总输出长度**」只实现了前一半。
按「未实现的维度不参与达标判定」本轮不补，缺口进 v1.1。

（阶段 1 单轨时这张表是三点恒定 75/25 且 P1 出现「总字数反而上升」，补轨后都消失——
**那是 n=1 的假象**。）

## 二、F3b · 兜底判断

### 2.1 四条设计判断

| # | 判断 | 理由 |
| --- | --- | --- |
| 一 | **标注形态，不做门** | 三种情况里只有「完全没提」该阻断，而它在评测集里 5/30。为少数情况给所有轮次加分支不划算；模板文案违反 §10「兜底文案必须具体」 |
| 二 | **收到两分类** | 「内容在图里」原定走规则，零模型成本。**机制被推翻，见 2.2** |
| 三 | **必须带校准** | 用 `检索评测集` 现成 30 题，不新建标注集。**但这不是 §8.5 的 judge 校准**，结果不得用于论证 B 类可启用 |
| 四 | **一次引入 14.129** | 同时回答三件挂着的事：`image_only` 通道验证 · 跨学科复现 · 两分类在第二门课上准不准 |

### 2.2 我指定的规则通道恒为空集

原机制是「`skipped_pages` ∩ 检索命中页」。**这个交集永远是空的**——
`image_only` 页不产生切片，不可能出现在命中页里。
这写在 `retrieval/README.md` §四，**信息是全的，漏的是一次范围核对**。

两条替代信号也不成立：邻接（±1）2 题对 1 题；跳过块前的标题页两题都没命中
（中文提问与纯英文标题没有语义重合）。

**替代机制 G03a**：不做逐题判定，改为「判断为**非 `covered`** 且该课件跳过页非空 →
把跳过页清单作为**限定语**注入讲解 prompt」。仍是零模型成本，误差方向单向
（多说一行限定语），而且**它真的会触发**。

**第一版门槛也定错了**：原定只在 `insufficient` 上触发，校准显示两道题只触发一道——
Q029 判 `partial` 是合理的，**模型看不到跳过页内容，没有依据判 `insufficient`**。
把门槛建在一个模型无法可靠给出的判断上，2 题漏 1 题。放宽到「非 `covered`」后触发 8/8。

**这次改动改在跑批之前，依据是校准数据**——先跑便宜的校准再花大钱，
它在花钱之前暴露了机制问题。

### 2.3 类别定义在模型看得见的范围内

模型只看得到检索片。若检索漏了那一页，它**无法知道**那是课件没讲还是检索没取到。
要求它区分等于要求它报告一个观测不到的量。

| 类别 | 语义 | 刻意不写成 |
| --- | --- | --- |
| `insufficient` | 取到的片段不足以回答 | ~~课件没有讲~~ |
| `partial` | 片段提到主题但没回答这一层 | ~~课件提了没展开~~ |

**错误区分放到评测侧归因分解**，不放 prompt 里。

### 2.4 校准结果

| | 判「不够」 | 判「够」 |
| --- | --- | --- |
| 实际该说「不够」(n=10) | **10** | **0** ← 漏报，贵 |
| 实际该说「够」(n=20) | 12 | 8 ← 误报，便宜 |

- **召回 10/10**：贵的那个方向一次没漏
- **误报 12/20 = 60%**：偏保守，但这是便宜的方向。看理由是**判断标准偏严不是判错**
- 无效输出 0/30；两次不一致 4/30（n=2 只报计数，不解释成稳定性）

**G11 归因分解**：16 个错误里 **14 个是判断本身、2 个是检索漏**。
不分解的话那 2 题会被记成 judge 不准，**然后有人去调 prompt——修一个不在那里的东西**。

达标线仍为**占位待定**：要定它得先回答「多保守算太保守」，取决于用户对多余边界说明的容忍度。

### 2.5 成本与延迟

| 项 | 实测 |
| --- | --- |
| 判断成本 | **$0.00126 / 轮**（单轮总成本 +4.8%） |
| 判断延迟 | 1,406 ms（P90 1,595） |

比方案估的（+12% / +1–2 s）便宜也快。**严格串行**：输入是检索结果、输出进生成 prompt，
既不能与检索并行也不能与生成并行。**只能压小，不能藏掉。**

**它不是延迟超标的原因，也不是解法**——主项是生成本身。

### 2.6 ⚠️ G13 · 这一跳的收益没测出来

| 组 | 显式说明边界 |
| --- | --- |
| 有判断 | **2 / 12** |
| 无判断 | **1 / 12** |

**2 vs 1 在 n=12 上不可区分。这一跳花了 4.8% 成本和 1.4 秒，
没换来可观测的讲解行为变化。**

两个原因本轮分不开：① 22.081J 的提问大多确实能被片段回答；
② 讲解 agent 拿到提示后仍以自己判断为准。要分开需要构造一批「课件确实没讲」的提问序列。

### 2.7 跨学科与 `image_only` 通道

14.129 lec02（区块链与金融），P0/P3 各 1 轨 6 轮：

| | 触发率 | 有审查达标 | 无审查达标 |
| --- | --- | --- | --- |
| P0 | 2/6 | 6/6 | 4/6 |
| P3 | 5/6 | **6/6** | **0/6** |

**方向与 22.081J 一致**，最严档无审查组全军覆没。⚠️ n=1 轨/点，
只支持「与 22.081J 同向」，不支持「在 14.129 上独立成立」。

`image_only` 通道**第一次有真实数据流过**，规则通道触发 8/8。
但对照 n=2，且**基线里那个错误（说「课件里没有提到」）根本没发生**——
**本轮没能演示这一跳防住了它。**

### 2.8 合规：实盘检索器没有排除受限页

`build_retriever` 没有应用 `RESTRICTED_PAGES`。22.081J 没有受限页所以不咬人，
**14.129 有 8 页第三方保留权利内容**——受限页会照样进 prompt，**没有任何报错**。
已修，复用 `retrieval.corpus.RESTRICTED_PAGES`，不重抄页号。

### 2.9 超支 1.8×（$1.4112 vs 估 $0.80）

两个原因：P3 在 14.129 上触发 5/6 重生成（估算按 22.081J 的触发率推的）；
补跑了一个方案里没有的 14.129 无判断对照组——**没有它，2.7 那张表不可归因**。
那笔钱买的是「这个数能不能读」。

## 三、被数据推翻的判断（第 5 次）

| # | 我判断的 | 数据说的 | 推翻的是什么 |
| --- | --- | --- | --- |
| 1 | 图注术语不必收 | 占分母 42% | 对**课件**的假设 |
| 2 | 漂移是「变长后衰减」 | 第 1 轮全为 0 | 对**模型**的假设 |
| 3 | 检索是压成本主要手段 | 输出占 68% | 对**成本结构**的假设 |
| 4 | G1 用常用词表近似即可 | 正文召回 17% | 对**自己方法**的假设 |
| **5** | **「课件会话内不变 → 必须启用 prompt caching」（PRD §7.3）** | **system 段 406 token < 最小可缓存 1024，断点不生效** | **对<b>架构</b>的假设** |

**第 5 次与前四次的区别：前四次要跑完实验才知道，这次 sanity check 就够了。**
406 与 1024 是两个确定量，不是统计结论。

这类假设值得单独归一类——**只需要一次量纲检查、却从没有人做过那次检查**。
它们读起来完全合理，因为**写下它的时候确实是对的**；错的是它跟着架构一起变了，而句子没变。

**便宜的检查方法**：每次架构改动后，把 PRD 里带「因此 / 所以 / 必须」的句子拿出来，
逐句问「**这句话的前提还在吗**」。

接检索后实际被缓存的只剩对话历史（第 2 轮起 78/78 命中），**省的是历史，不是课件**。

## 五、同一件事改过几次

| 项 | 演化 | 触发改动的是什么 |
| --- | --- | --- |
| 实验设计 | 「默认 vs 极端」二元 → **配置扫描** | 二元只是把外推方向反过来 |
| 主判据 | 逐点判读带 → **跨点单调性 + 跨轨同向** | 判读带会让最关心的两点判「不可分辨」 |
| `readout.band_of` | 按区间遍历 → **按判读带原文写死** | `6/12` 落进先匹配到的「不可分辨」，**本该有结论的点变成没结论** |
| 括注排除口径 | 术语表（A）→ **形态规则（B）** | A 靠这门课恰好有术语表，生产多课程没有 |
| 三口径分歧的依据 | 六份旧样本 → **本批次 transcripts** | 旧样本测自 prompt 要求写括注的配置 |
| E10 混合形态 | 改判据 → **不改判据，报定义式分解** | 分解是一个除法，无阈值无自由参数 |
| §10 兜底判据 | 检索分数 → **模型判断 + 跳过页限定语** | §10.1 实测四个 embedding 模型全部重叠 |
| G03 机制 | 跳过页 ∩ 命中页 → **非 `covered` + 清单非空** | 交集恒为空集 |
| G03 门槛 | `insufficient` → **非 `covered`** | 模型没有依据给出 `insufficient` |
| 校准重复次数 | 3 次 → **2 次，只报计数** | n=3 时 2/1 与 3/0 的差别不构成证据（R17） |
| `verify_scan` 分组 | `(点, 轮)` → **`(臂, 点, 轮)`** | 两条臂都跑 P0，报出并不存在的分歧 |
