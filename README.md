# AI 课件讲解助手

个人 0→1 项目。上传课件 → 解析切片 → 检索 → 按个人风格讲解。

**本文件只是一张目录地图**，不复制任何口径与结论——每处「权威出处」列在下面，
读那一份。地图之外不写事实，就不会有第二份跟着漂的副本。
