## 为什么重测

简历上的「混合检索使正确页面在前 5 条结果中的完整命中率由 83% 提升至 100%」来自
`eval_hybrid_20261007.md`（线上，19 道有答案的题）。重读之后有三个问题，与样本量无关：

1. **83% 是把两个 tag 分组加起来算的**：(5+15)/(7+17) = 20/24。5 道题同时带两个 tag，被计了两次；
   R15 明文禁止相加。当时只存了分组汇总，按题的命中率算不出来（在 15/19 到 17/19 之间）。
2. **提升不来自「混合」**：C2（改写 + 向量 + 词法 + RRF）与 C0（只有向量）完全相同；两轮各多中的 2 题都来自 C2 → C3 的**重排**。
3. **C3 两轮都满分**——到天花板了，同难度的题加多少都分不出各环节。

## 评测集 v2

- 语料：22.081J（39 页）+ 11.201（15 页），共 54 页、每页一片。不加新课件（用户 2026-10-15 定）。
- 100 题：同义改写 35、跨页 25、精确词 15、多轮追问 15、无答案 10。出法见 `实验脚本/检索评测集/v2/生成.py`：

- **冻结**：`评测集.json` 提交到 git 之后才跑检索。之后不改题、不改答案页、不剔题。
- 已知限制：单人复核、模型出题（中文语义复用机器挡不住）、两份英文课件、两个学科。

## 指标与判据

指标：full-hit@5（正确页全部进前 5）为主，page-recall@5 并列报。无答案题不进命中率，只报 top-1 相似度分布（R16）。

**主假设**：C3 的 full-hit@5 高于 C0（有答案的约 90 题）。
- 检验：双侧精确 McNemar，α = 0.05。
- 效应：命中率差，95% CI 用**按答案页分簇的 bootstrap**（同一页上的题相关，不当独立样本）。
- 说「全开比只有向量好」**同时要求** p < 0.05 **且** CI 下界 > 0。

**次要（逐环节归因）**：改写 C0 → C1（**只看 15 道多轮题**，单轮题上两组结构性相同）、词法 C1 → C2、
重排 C2 → C3、完整流程里的词法 C4 → C3。四个比较，Bonferroni 后 α = 0.0125；不过线的只报方向，不说「有收益」。

**R17（多条件同向重复）**：同一脚本再在 v1 的 24 道题（答案页在这两份课件里的）上跑一遍，作为第二个独立条件。
某一环节要说「有证据」，须 v2 过检验线**且** v1 同向（v1 单独不要求显著——它只有 19 道有答案的题）。

**天花板**：C3 ≥ 98% 时如实写「到顶」，不写成「提升到 100%」。

**按类**：五类分开报，**不相加**（R15）。

**回落**：改写 / 重排失败按生产的回落继续，计入成绩，回落次数单列。
