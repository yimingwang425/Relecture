## 四、已作废 —— `docs/F1/F1方案.md` 里被推翻的条目

每条给出**推翻它的证据**。没有证据的「感觉不对」不列在这里。

### 1 · §2.1 四条轴：详细程度**四档 → 三档**

| | |
| --- | --- |
| 方案原文 | `P0` 30–120 / **`P1` 40–90** / `P2` 25–55 / `P3` 15–40 |
| 现状 | **`P0` / `P2` / `P3`**，P1 退出用户可选档位 |
| 证据 | `P1(40–90)` 完全被 `P0(30–120)` 包含，而模型在两条指令下的自然段落长度都落在 40–90 里。**连续 8 次生成隶属集合恒相同**（第 4 次 P1 的 81.1 甚至比 P0 的 76.0 更长，方向是反的）。替代对 `P0 vs P2` **第 1 次生成即通过**。与项目先验一致：`scan/points.py` 给 P1 的定语就是「自然中枢仍在区间内，只是余量收窄」 |
| 口径 / 提交 | F23 / `252d1a5` |
