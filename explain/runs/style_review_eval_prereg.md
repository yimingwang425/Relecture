# 风格审查 agent · 评测 · 预登记（2026-10-12）

**本文件在跑任何一次风格审查之前写下并提交。** 结果出来后不改本文件；任何偏离写在结果文件的「偏离预登记」一节。
被测对象是已上线的 `explain/explain/style_review.py`（`STYLE_REVIEW_PROMPT_VERSION = "sr1"`，Haiku 4.5），
**评测前不改它的 prompt、工具与校验**。看过结果之后若要改，改后的版本只能在新的留出集上算数。

## 要回答的问题

1. **X 检出率**：讲解的讲法与学生存的偏好明显相反时，agent 打回（`rewrite`）的比例。按四条轴分开报。
2. **Y 误报率**：讲解按学生自己的偏好写的，agent 却打回的比例。
3. **Z 冲突时正确放行率**：学生存的偏好与这一句里明说的要求相反、讲解按这一句的要求写时，agent 放行（`ok`）的比例。
4. 代价：每次审查的成本、延迟（关键路径上，学生在等）、步数、工具用了什么、提交被退回几次。

## 数据

- **课件**：`f1_samples/synthetic_deck.md`（自写合成课件，非第三方内容，PRD §12.1）。
  上下文是**整份课件的 20 块全部喂入**，不检索：测的是讲法，不是检索；本地词法检索对中文提问取不到英文课件的块，
  而加查询改写又多一个与本评测无关的变量。
- **讲解生成**：生产讲解模型（`AnthropicModel()`，Sonnet）+ 生产 system（`build_system`）+ 生产风格规则
  （`render_all_style_rules`），单次调用、不走工具与审查——要的是「按某个讲法写出来的讲解」，不是链路。
- **四条轴、每条两个相反的取值**（非目标轴一律取默认值 `DEFAULTS`，口径 F01）：

  | 轴 | 取值 A | 取值 B |
  | --- | --- | --- |
  | detail_level | P0（详细） | P3（精简） |
  | use_examples | more | fewer |
  | structure | conclusion_first | buildup_first |
  | depth | what | derivation |

- **主集问题**：8 个关于特征值的问题（脚本里的 `QUESTIONS`）。每个问题 × 每条轴 × 两个取值各生成一段 → 64 段讲解。
- **冲突集（Z）**：每条轴 5 个问题，问题本身带一句与「存的偏好」相反的明确要求（脚本里的 `CONFLICT`）。
  讲解按这句要求的取值生成 → 20 段。
- 生成后**不挑**：除非调用失败或输出为空，全部进集。

## 审查条目（每条 = 一段讲解 + 一份「学生存的偏好」+ 一句提问）

| 集 | 怎么组成 | 期望 | 条数 |
| --- | --- | --- | --- |
| 符合（Y） | 讲解按取值 V 生成，偏好也是 V | `ok` | 64 |
| 偏离（X） | 同一段讲解，偏好换成该轴的相反取值 | `rewrite` | 64 |
| 冲突（Z） | 讲解按这句要求的取值生成，偏好是相反的那个，提问带着那句要求 | `ok` | 20 |
| 冲突对照 | 同一段讲解与偏好，提问**去掉那句要求** | `rewrite` | 20 |

同一段讲解既当「符合」又当「偏离」：agent 必须真的分辨讲法，只靠「这段写得好不好」判不出来。
冲突对照用来说明 Z 不是「什么都放行」换来的。所有条目都是第一轮（没有对话历史）。

## 判据（预先定死）

- 结论取 `StyleReviewRun.verdict`。`verdict = None`（agent 失败：超时、报错、步数用完）**按生产处置记为放行**，并单列条数。
- **X** = 偏离集里 `rewrite` 的比例；**Y** = 符合集里 `rewrite` 的比例；**Z** = 冲突集里放行的比例；
  冲突对照集里 `rewrite` 的比例一并报。
- **标签效度**：标签来自生成条件，生成模型不一定照做。用两条不花钱的检查报出标签可疑的条目，**不剔除、不改标签**，
  只在结果里另报一份「去掉可疑对之后」的数作为参考，标题数字始终是全集：
  - detail_level：同一问题的 P0 版总字数 < P3 版的 1.3 倍 → 这一对可疑；
  - 其余三轴：不做自动检查；agent 判错的条目逐条读，写明「讲解确实没照生成条件写」还是「agent 判错」。
    **这一步由 Claude 读，不是人工标注者**，结果里照实写。
- **达标线**：X ≥ 70%（四轴合计），Y ≤ 10%，Z ≥ 70%。不达标照样报数。

## 成本口径

- 单次审查成本 = agent 各步之和（`llm.PRICING`）。
- 「单轮成本增加百分之几」= 审查均值 / agent 链路课件题单轮均值 $0.027（2026-10-08 真模型验收，n = 5）。
  每一版讲解都要审一次，重写的那一版再审一次；这里只报单次。
